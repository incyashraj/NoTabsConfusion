# Privacy

NoTabsConfusion runs on your Mac and does not talk to a server.

- There is no account and no analytics.
- The app does not send window titles, screenshots, or any other data off the machine.
- It asks macOS for access so it can tell which window is in front, read that window’s frame, and read the app icon. Those values are used only to draw the border while Mission Control is open.
- Color, width, and glow choices in Preferences are stored in local User Defaults on this Mac.

The current build saves those preference values. The border colors you see are still the built-in purple, amber, and teal styles.
