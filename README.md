# NoTabsConfusion

Menu bar app for macOS, labeled FocusBorder. While Mission Control is open it draws a colored border around your recent windows and shows each app's icon.

Free. Not on the App Store.

## Download

**[Download NoTabsConfusion 1.0](https://github.com/incyashraj/NoTabsConfusion/releases/latest)**

- Apple silicon Mac
- macOS 26.2 or later

## Install

1. Unzip `NoTabsConfusion-1.0.zip`.
2. Move `NoTabsConfusion.app` into Applications.
3. Open it. There is no Dock icon. The scope mark in the menu bar is the app.
4. If macOS says it cannot verify the developer, open System Settings, go to Privacy & Security, and click Open Anyway.
5. Turn on Accessibility for NoTabsConfusion when macOS asks. The app needs that to see which window is in front.

## Use

Open Mission Control. Borders show on your recent windows. Click the menu bar icon, then Preferences, to change the color, width, and glow. Quit from that same menu.
