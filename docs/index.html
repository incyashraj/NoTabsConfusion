NoTabsConfusion

A free menu bar app for Mac. While Mission Control is open, it draws a colored border around the windows you were just using, with each app’s icon.

Download for Mac Source on GitHub

What it shows

Most recent windowPurple to blue glow, plus the app icon
The window before thatAmber border
One further backTeal border

This is a diagram of the three border styles, not a photo of a desktop. Borders stay hidden during normal use and appear when you open Mission Control.

Install

  1. Download NoTabsConfusion-1.0.zip and unzip it.
  2. Move NoTabsConfusion into Applications and open it.
  3. There is no Dock icon. The scope mark in the menu bar is the app. Quit is on that menu.
  4. The first time, macOS asks for access so the app can see which window is in front. Allow it in System Settings. The app also needs Accessibility access for the same reason.
  5. If macOS says it cannot verify the developer, open System Settings, go to Privacy & Security, and click Open Anyway. The build is signed with a Developer ID. Notarization is still waiting on an Apple developer agreement.

Requires an Apple silicon Mac on macOS 26.2 or later. The menu calls the app FocusBorder. The download name is NoTabsConfusion.

Privacy

  • No account, no ads, and no network requests.
  • Window titles, frames, and app icons are read on your Mac so a border can be drawn. Nothing is uploaded.
  • Details are in the privacy note.
