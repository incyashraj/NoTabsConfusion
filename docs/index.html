NoTabsConfusion

Free menu bar app for Mac. In Mission Control it draws a border around the windows you were just using, with each app’s icon. The menu calls it FocusBorder. It is not on the App Store.

Download NoTabsConfusion 1.0

Apple silicon · macOS 26.2 or later · Source

What you see

  • Most recent window: a purple-blue border and the app icon.
  • The window before that: an amber border.
  • One further back: a teal border.

Borders stay hidden until you open Mission Control.

Install

  1. Unzip the download and move NoTabsConfusion into Applications.
  2. Open it. There is no Dock icon. The scope mark in the menu bar is the app.
  3. Allow access when macOS asks, so it can see which window is in front. It also needs Accessibility.
  4. If macOS blocks the first open, go to System Settings → Privacy & Security and click Open Anyway.

Privacy

No account, no ads, and no network requests. Window frames and app icons stay on your Mac. Privacy note.
